# Personal Expense Analyzer

A full-stack personal expense management and AI-powered financial insights application.

## Tech Stack

### Frontend
- React
- Vite
- CSS
- Responsive UI

### Backend
- FastAPI
- SQLAlchemy
- JWT Authentication
- Google Gemini API

### Database
- PostgreSQL

## Features

- User registration and login
- JWT authentication
- Add expenses
- Edit expenses
- Delete expenses
- Expense categories
- Daily analysis
- Weekly analysis
- Monthly analysis
- Category-wise spending analysis
- Spending trend visualization
- AI-powered financial insights
